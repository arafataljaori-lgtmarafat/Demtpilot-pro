# DentPilot

### نظام إدارة ومتابعة مرضى الأسنان

تطبيق ويب طبي (PWA) بواجهة لوحة تحكم، تنقّل فوري دون إعادة تحميل،
قابل للتثبيت على الهاتف، ويعمل دون إنترنت. كل البيانات محلية على الجهاز (`LocalStorage`).

## ✨ المميزات

- **إعداد أول تشغيل:** شاشة تطلب اسم الطبيب والتخصص واسم العيادة، ثم يُستخدم الاسم في كل التطبيق.
- **لوحة تحكم (Dashboard):** بطاقات للمرضى · مواعيد اليوم · المواعيد المتأخرة · الإحصائيات · التقارير · النسخة الاحتياطية · الإعدادات · إضافة مريض.
- **مواعيد اليوم:** قائمة مباشرة أسفل اللوحة مع أزرار متابعة/اتصال/واتساب.
- **ملف المريض = نظام علاج كامل:** جلسات علاج غير محدودة (رقم تلقائي، تاريخ ويوم الأسبوع، وقت، علاج منفّذ، مبلغ مدفوع، ملاحظات، موعد قادم، خانة إنجاز)، **خط زمني طبي رأسي**، و**سجل دفعات** يُحدّث الإجماليات تلقائياً (التكلفة/المدفوع/المتبقي).
- **إنهاء العلاج والأرشفة:** زر «إنهاء العلاج» ينقل المريض إلى **المرضى المكتملين** دون حذف أي بيانات، مع **استعادة** و**حذف نهائي**.
- **طباعة احترافية A4:** تقرير يشمل معلومات المريض والخط الزمني وكل الجلسات وسجل الدفعات والإجماليات وتاريخ الإكمال واسم الطبيب والعيادة وشعار DentPilot.
- **تنقّل SPA فوري** بين الصفحات دون إعادة تحميل (مع دعم زر الرجوع).
- **تلوين حالة المواعيد:** متأخر · اليوم · الغد.
- **بحث صغير احترافي** بجانب زر الإضافة (بالاسم/الهاتف/العلاج).
- **متابعة المريض:** واجهة جاهزة (نظرة عامة) لاستقبال الجلسات والدفعات لاحقاً.
- **إكمال العلاج:** نافذة تأكيد جاهزة (النقل للأرشيف يُفعّل في تحديث قادم).
- **النسخة الاحتياطية:** تصدير/استيراد كل البيانات في ملف JSON.
- **التنبيهات:** قبل موعد الجلسة بيوم وفي يومه، مع تنبيه صوتي.
- **PWA:** قابل للتثبيت ويعمل دون إنترنت. متجاوب على Android و iPhone و Tablet.

## 🎨 الهوية البصرية

ألوان طبية: **Teal · White · Navy**، وأيقونة مخصّصة (سن + ملف مريض + حرفا **DP**).

---

## 🚀 التشغيل المحلي

افتح **`index.html`** بأي متصفح حديث.

> 💡 ميزات PWA (التثبيت والعمل دون إنترنت) تتطلّب رابط **HTTPS** (Netlify / GitHub Pages)
> أو خادم محلي، وليس فتح الملف بصيغة `file://`.

```bash
python3 -m http.server 8080   # ثم: http://localhost:8080
```

---

## 🌐 النشر على Netlify

اسحب مجلد المشروع كاملاً إلى منطقة **Deploy** في [netlify.com](https://www.netlify.com)
(أو اربط مستودع GitHub). لا حاجة لأمر بناء — المشروع ثابت. الجذر يحتوي `index.html`.

## 🌐 النشر على GitHub Pages

ارفع الملفات (مع بقاء `index.html` في الجذر) ثم:
**Settings → Pages → Deploy from a branch → `main` / `(root)`**.

## 💾 البيانات والتوافق

- بيانات المرضى تُحفظ بمفتاح `LocalStorage` نفسه المستخدم في الإصدارات السابقة (توافق كامل مع البيانات القديمة).
- بيانات الطبيب تُحفظ بمفتاح منفصل خاص بالإعدادات.
- كل البيانات محلية على الجهاز ولا تُرسَل لأي خادم.
